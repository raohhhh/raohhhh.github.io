英文原标题：RAN sharing security: MOCN, MORAN and the trust problems of a shared radio network

RAN sharing lets two or more mobile operators serve their subscribers from the same radio access network: the same sites, the same baseband and radio units, and in some models the same spectrum. It is now a mainstream deployment choice, driven by the cost of 5G densification and rural coverage obligations, and in several markets regulators are actively encouraging or mandating it. In August 2026, for example, Malaysia's regulator brought 4G multi-operator core network (MOCN) access into its regulated access framework. RAN sharing security is the discipline of making sure that sharing hardware does not also mean sharing trust, keys, visibility or failure. The direct answer is that a shared RAN node becomes a common point of compromise for every operator that uses it. It holds access stratum keys for all partners' subscribers, terminates user plane encryption for all of them, connects to several independent cores, and is managed by one party on behalf of others. The security model therefore rests on strict separation of control, management and transport per partner, on clear accountability between host and guest operators, and on testing that checks those separations actually hold. This article walks through the sharing models, the specific risks each introduces, and the controls and tests that address them. What RAN sharing is and how the main models differ RAN sharing is any arrangement where a single radio access network serves multiple PLMNs. The models differ in how much is shared, and each step towards deeper sharing moves more trust into common infrastructure. 3GPP defines network sharing architectures in TS 23.251 for earlier generations and in TS 23.501 for the 5G System. Industry practice distinguishes several models: Passive sharing. Operators share sites, masts, power and shelters, but each runs its own active radio equipment. The security impact is mainly physical access to sites. Multi-operator RAN (MORAN). Operators share active radio and baseband hardware, but each uses its own spectrum and broadcasts its own cells. Logically the cells are separate, yet they run on common equipment and common software. Multi-operator core network (MOCN). Operators share the radio equipment and the spectrum. A shared cell broadcasts a list of PLMN identities in its system information, and the RAN routes each device's signalling to the core of the operator that the device selects. Each operator keeps its own core network. Gateway core network (GWCN). In addition to the RAN, some core elements are shared. GWCN is defined in TS 23.251 for earlier generations but is less common in current deployments. Neutral host. A third party, rather than one of the operators, owns and runs the shared RAN and offers it to several operators. This model is frequent in venues, transport and indoor coverage.
