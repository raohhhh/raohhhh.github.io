攻击事件背景： 在移动通信网络中，3G和4G的认证向量（Authentication Vectors）本应是完全分离且不可互相转换的。然而，P1 Security的研究人员发现，部分移动网络运营商（MNO）在通过漫游互连接口分发认证向量时存在安全隐患。某些用户的3G认证向量可以被转换为适用于任何PLMN（公共陆地移动网）的4G认证向量。这使得拥有SS7互连接口访问权限的攻击者能够拦截这些用户的4G无线通信。 时间线： - 2019年初：P1 Security开始调查认证向量在漫游接口上的分发情况。 - 2020年3月：原计划在Troopers Telco Security Day上讨论该研究，因新冠疫情取消。 - 2021年2月：将研究提交给GSMA以引起MNO生态系统的重视。 - 2026年8月20日：通过官方博客正式发布该研究报告。 攻击原理： 4G设计时引入了安全增强机制，其服务网络用于保护用户流量的主密钥（Kasme）是由3G的CK、IK以及服务网络的PLMN-ID派生而来的。这意味着4G认证向量是为特定服务网络定制的，不能被广播不同PLMN-ID的网络使用。该机制旨在防止攻击者结合IMSI-catcher和漫游集线器访问进行攻击。然而，研究发现，如果攻击者能够获取到3G认证向量（包含CK、IK），他们可以绕过这一限制，自行派生出适用于任意PLMN的4G认证向量。 攻击详情： 攻击者首先需要获取SS7互连接口的访问权限。通过TCAP-MAP协议请求并获取特定用户的3G认证向量后，利用3G和4G认证协议输入输出（如RAND, SQN和SRES, AUTN, CK, IK）的继承关系，将3G向量转换为4G向量。此外，研究还发现在Diameter请求中，关于寻址和PLMN识别的做法存在缺陷，这严重阻碍了运营商对4G认证向量向漫游伙伴分发过程的有效控制，进一步放大了安全风险。 攻击特征： 1. 跨代利用：利用3G认证向量生成4G认证向量，突破代际隔离设计。 2. 协议滥用：通过SS7（TCAP-MAP）和Diameter信令协议在漫游互连层面发起攻击。 3. 绕过PLMN绑定：绕过了4G安全机制中Kasme与PLMN-ID绑定的防护，使得攻击者可针对任意PLMN伪造4G接入。 4. 结合IMSI-catcher：攻击通常需要结合IMSI-catcher和漫游网络访问权限，以实现对4G无线通信的拦截。

英文原标题：All authentication vectors are not made equal

Abstract In mobile networks, 3G and 4G authentication vectors are completely separate and should not be convertible to each other. P1 Security however discovered that some MNOs distribute over roaming interconnects, for certain subscribers, 3G authentication vectors that can be turned into 4G ones for any PLMN. This enables attackers, when they have access to an SS7 interconnect, to intercept the 4G radio communications of those subscribers.Moreover, we found that some practices in terms of addressing and PLMN identification in Diameter requests for 4G authentication vectors, may be a serious obstacle for MNOs to properly control how they distribute 4G authentication vectors to roaming partners. The report available at the end of this post provides extended information related to this research, which has been acknowledged by the GSMA CVD programme . Subscriber Authentication Let’s first have a quick reminder on how subscribers are authenticated in mobile networks. In the course of its evolution from 2G to now 5G, the cellular technology has evolved, together with the security level provided to subscribers and the way they are authenticated. A big improvement happened when 3G was developed: a mutual authentication procedure, relying on a new protocol, was introduced. It brought mutual authentication between the subscriber and the network. It required the introduction of new SIM cards too, in order to support this protocol and algorithm ( Milenage being often chosen). The rollout spread over several years. Situation with 4G When 4G was designed, the subscriber authentication procedure has evolved again. It was still built upon the USIM application, its authentication algorithm (e.g. Milenage ), and the inputs and outputs of the 3G authentication protocol: { RAND , SQN } and { SRES , AUTN , CK , IK} . In this way, no new SIM cards were required to be rolled out again. An enhancement was however introduced in 4G handsets and networks: the master key to be used by the serving network for protecting the subscriber traffic (i.e. Kasme ) is derived from CK , IK and the serving network PLMN-ID (i.e. the MCC-MNC code broadcasted by its base-stations). The serving network hence receives from the home network the following authentication vector: { RAND , SRES , AUTN , Kasme }. That means that a 4G authentication vector is produced for a specific serving network, and cannot be used to attach a 4G subscriber on a network whose base-stations broadcast a different PLMN-ID . This enhancement has been introduced in order to provide a way for MNOs to gain more control on the distribution of 4G authentication vectors, with the increasing number of roaming partners all over the world. It enables them to control (and eventually enforce) which roaming partners request 4G authentication vectors for which PLMN-ID .
